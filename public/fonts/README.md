# Signature font

Allura Regular is bundled, unmodified, from the Google Fonts `ofl/allura` directory:
https://github.com/google/fonts/tree/main/ofl/allura

Copyright 2010 The Allura Project Authors. Distributed under the accompanying SIL Open Font License 1.1 (`OFL-Allura.txt`). The same font file is used by the original-document editor and completed-PDF renderer. Regular responses remain Arial; unsupported signature characters retain the existing Unicode-safe response font instead of being omitted.
